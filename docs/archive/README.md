# Archive

This directory contains historical documentation that is no longer actively maintained. These files are preserved for reference — they capture decisions, progress, and context from earlier development phases.

## Structure

- **phases/** — Consolidated summaries of development phases (Phase 1-7)
- **issues/** — Investigation and resolution notes for significant issues
- **misc/** — One-off fix records, PR references, and other historical notes
